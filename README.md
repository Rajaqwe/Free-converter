# Free-converter

Static GitHub Pages edition of the PDF + AI → PLT Batch Cutter v17.

This public edition needs no login and uses no backend. PDF previews are rendered in the browser with PDF.js. Actual PLT/ZIP conversion needs the original Node/Ghostscript/pstoedit server, which is intentionally not included here.

https://rajaqwe.github.io/Free-converter/
